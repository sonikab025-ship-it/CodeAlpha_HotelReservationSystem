# Hotel Reservation System

This project is developed using Java as part of the CodeAlpha Java Programming Internship.

The Hotel Reservation System is a simple console-based application that allows users to view available rooms, book rooms, and manage reservations. The program demonstrates the use of Java fundamentals such as arrays, loops, conditional statements, and user input handling using the Scanner class.

## Features
- View available rooms
- Book a room
- Prevent double booking
- Simple console-based interface

## Technologies Used
- Java
- Arrays
- Scanner Class
- Conditional Statements
- Loops

## How to Run

1. Compile the program  
javac HotelReservation.java

2. Run the program  
java HotelReservation
